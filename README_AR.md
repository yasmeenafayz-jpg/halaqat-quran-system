# نظام حلقات التحفيظ — حزمة النشر النهائية

هذه الحزمة هي النسخة التي سنرفعها في النهاية، وليست ملفًا للتثبيت على الهاتف.
الهاتف بعد النشر يحتاج فقط إلى فتح رابط PWA وإضافته للشاشة الرئيسية.

## ما تم تجهيزه
- PWA عربية خفيفة: واجهة + manifest + service worker.
- Cloudflare Worker كخادم API.
- Cloudflare D1 كقاعدة بيانات سحابية.
- الطلاب والحلقات الفردية والجماعية.
- حضور مستقل لكل طالب.
- الخطط: حفظ جديد، مراجعة، حفظ ومراجعة، سرد تراكمي.
- المقادير: ربع وجه، نصف وجه، وجه، ربعين، حزب، جزء.
- موضع المصحف وتاريخ الورد والتقدم.
- خطة الطالب والورد التالي المبني على آخر صفحة مسجلة.
- اختبارات ومتوسط تراكمي.
- مالية ودفعات ورسوم وغرامات، مع منع الغرامة عن الحلقة الفردية.
- لقاءات وروابط Zoom/Teams.
- Telegram Bot على الخادم فقط مع تذكير مجدول ومنع التكرار.
- نسخ احتياطي JSON.
- أسرار الخادم عبر Cloudflare Secrets، وليس داخل الواجهة.
- نقطة تكامل Quran Foundation Content API على الخادم فقط.

## ما لا يوضع على الهاتف
لا يحتاج الهاتف إلى Python أو Node أو Docker أو ملفات قاعدة البيانات أو مفاتيح Telegram أو مفاتيح المصحف.

## مرحلة الرفع الوحيدة المتبقية
1. إنشاء حساب Cloudflare مجاني.
2. إنشاء D1 Database باسم halaqat-db.
3. وضع database_id في wrangler.toml.
4. تنفيذ schema.sql على D1.
5. إضافة Secrets:
   - ADMIN_PASSWORD
   - SESSION_SECRET
   - TELEGRAM_BOT_TOKEN (عند إنشاء البوت)
   - QF_CLIENT_ID
   - QF_CLIENT_SECRET (بعد طلب الوصول من Quran Foundation)
6. نشر Worker + Assets.

لا تبدأي الرفع الآن إذا لم تكوني مستعدة. هذه الحزمة محفوظة لتكون آخر حزمة نرفعها.

## ملاحظة عن المصحف
لا نضع نص المصحف الكامل داخل الهاتف. الخادم يستدعي بيانات المصحف من المصدر المرخص بعد تفعيل بيانات الاعتماد، ثم يعرض الصفحة/الموضع المطلوب.

## الإضافة الجديدة: المالية والتحويلات
- يمكن ضبط رقم التحويل المالي من قسم الإعدادات.
- عند تسجيل دفعة يمكن حفظ رقم التحويل، طريقة الدفع، والتاريخ والوقت.
- كل حركة مالية تحفظ في سجل الطالب مع `transaction_at`.
- الغرامات لا تزال مقصورة على الحلقات الجماعية.

## Telegram
النظام مجهز ببوت Telegram على الخادم:
- كل حلقة جماعية لها `Telegram Chat ID` مستقل.
- التذكير يرسل إلى مجموعة الحلقة قبل الموعد.
- لا يرسل التذكير مرتين لنفس اللقاء.
- رابط Zoom/Teams يضاف تلقائيًا إلى الرسالة إذا كان موجودًا.
- Bot Token لا يوضع في الواجهة، بل كـ Secret على الخادم باسم `TELEGRAM_BOT_TOKEN`.

### إنشاء البوت
لا يمكن للمشروع إنشاء حساب Telegram أو البوت نيابة عنك؛ إنشاء البوت يتم مرة واحدة من Telegram عبر BotFather. بعد الحصول على Token يوضع كـ Secret في Cloudflare Worker فقط، وليس في ملفات الهاتف.

بعد إنشاء البوت، أضيفي البوت إلى مجموعة الحلقة واجعليه قادرًا على إرسال الرسائل، ثم ضعي Chat ID للحلقة في إعدادات الحلقة. استخدمي زر اختبار Telegram للتأكد من الإرسال.

## حسابات الطلاب
أضيف في هذا الإصدار حساب مستقل لكل طالب. الطالب يرى بياناته فقط، ولا يصل إلى بيانات بقية الطلاب أو إعدادات الإدارة. كما أضيفت خانة «معفى من الدفع» للإدارة فقط، ولا يتم إرسالها إلى حساب الطالب.
