# الأوَّابين — حزمة التطوير الاحترافية

هذه الحزمة مصممة لتُضاف يدويًا إلى المستودع الحالي `halaqat-quran-system`، ولا تفترض حذف النسخة الحالية.

## الهدف
نقل النظام تدريجيًا من التخزين المحلي إلى بنية قابلة للتوسع:
- Cloudflare Worker API
- Cloudflare D1
- صلاحيات إدارة/معلمة/طالب
- إعدادات قابلة للتغيير
- الحلقات والمستويات والورد والحضور والاختبارات والمالية والاشتراكات
- Telegram من الخادم
- Audit Log
- نسخ احتياطي واستيراد
- PWA

## ترتيب الإضافة
1. انسخ `schema.sql` إلى جذر المشروع.
2. أضف `migrations/001_initial.sql`.
3. أضف `worker/` إلى المشروع أو ادمج محتواه مع Functions الحالية.
4. أضف `wrangler.toml` بعد ضبط `database_id`.
5. لا تضع أي Secret في GitHub.
6. راجع `config/default-settings.json`.
7. نفّذ الاختبارات قبل تحويل الإنتاج.
8. احتفظ بنسخة احتياطية قبل أي migration.

## Secrets
- ADMIN_PASSWORD
- SESSION_SECRET
- TELEGRAM_BOT_TOKEN
- QF_CLIENT_ID
- QF_CLIENT_SECRET

الأخيران اختياريان حتى تفعيل مزود المصحف الخارجي.

## مبدأ التطوير
لا تحذف وظائف النسخة الحالية. ادمج الوحدات الجديدة تدريجيًا.
