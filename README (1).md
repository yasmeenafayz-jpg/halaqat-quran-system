# الأوَّابين — النسخة النهائية

نسخة موحدة خفيفة للهاتف، مبنية لتعمل على Cloudflare Pages + D1.

## تشغيل محلي
npm install
npm run build

## النشر
Build command: `npm run build`
Output directory: `dist`

أنشئ D1 باسم `alawabin-db` ثم ضع Database ID الحقيقي في إعداد Cloudflare.
لا ترفع الأسرار إلى GitHub.
